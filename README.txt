CREATIVE ARTS TOKYO — サイト一式
==================================

■ ファイル構成（すべて同じ階層に置いてください）
  index.html   … トップページ本体
  style.css    … デザイン（色・レイアウト）
  script.js    … スマホメニューの開閉、お問い合わせフォームの送信処理
  logo.png     … ロゴ画像（フッターで使用）

■ 中身の直し方
  - 文章を直したい → index.html 内の該当する日本語部分をそのまま書き換えてください（タグは残す）
  - 色を変えたい → style.css の先頭 :root{ ... } 内にある色（例: --gold:#c49a45;）を変更
  - 公演履歴を追加したい → index.html の <div class="timeline"> 内に、既存の <div class="t-item"> ブロックをコピーして年月・タイトル・会場を書き換えてください

■ お問い合わせフォームの設定（必須の作業です）
  index.html 内のお問い合わせフォームは、現在ダミーのURL（YOUR_FORM_ID）のままなので、このままでは送信できません。
  下記の手順で、無料のFormspreeというサービスと連携してください。

  1. https://formspree.io にアクセスし、無料アカウントを作成（受信したいメールアドレスで登録）
  2. 「+ New Form」でフォームを1つ作成し、表示される Form ID（例: xzbldlnn のような文字列）を控える
  3. index.html 内で3箇所ある
       action="https://formspree.io/f/YOUR_FORM_ID"
     の YOUR_FORM_ID の部分を、すべて控えたIDに書き換える（3フォームとも同じIDでOK。件名で自動的に区別されます）
  4. 保存してアップロードし直す
  5. 実際にサイトのフォームから1回テスト送信すると、Formspreeから確認メールが届くので「Confirm」をクリックして有効化する

  ※ 無料プランは月50件までの送信という上限があります。超える場合は有料プランへの変更が必要です。

■ 公開の仕方（低コスト案）
  1. GitHub Pages / Netlify / Cloudflare Pages などの無料ホスティングにこのフォルダをアップロード（実質0円、独自ドメインも接続可能）
  2. 独自ドメイン（例: creativeartstokyo.jp）はドメイン取得サービスで別途取得（年間1,000〜2,000円程度が目安）
  3. お問い合わせフォームを機能させたい場合、Formspreeなど無料枠のあるフォーム送信サービスと連携するのが簡単です（サーバー不要）

  ※ 具体的な手順（GitHubへのアップロード方法など）が必要であれば、いつでもお手伝いします。
